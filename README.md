# 日常 Daily — 管理後台

獨立的 Vue 3 + Vite 專案，目前提供可操作的後台 Demo，供確認版面與流程。尚未串接登入、管理員授權或管理 API；所有資料均為示意，操作只保留在頁面記憶體，重新整理即還原。

## Demo 內容

- 管理總覽：會員狀態摘要、最近異動及常用入口。
- 會員管理：會員名稱／帳號／信箱獨立模糊搜尋（忽略英文大小寫及查詢頭尾空白）、角色／狀態下拉篩選（按「查詢」或 Enter 才套用條件並回第一頁；分頁沿用上次查詢，重設只清空輸入）、分頁、詳情抽屜、模擬啟用／停用與撤銷登入。
- 分類管理：記帳／運動頁籤、新增、編輯、模擬啟用／停用。
- 加入管理：邀請制與註冊審核制流程預覽，尚未定案；邀請代碼不可實際使用。
- 操作紀錄：示意操作同步記錄、搜尋及詳情。
- 支援桌面側欄及手機收合選單；直接以示意管理員身分進入，沒有實際登入功能。

## 開發

需要 Node.js 20.19+ 或 22.12+。從儲存庫根目錄執行：

```bash
cd Frontend/Admin
npm ci
npm run dev
```

目前開啟 `http://localhost:5174`。前台使用 5173，可同時啟動。
目前 Vite 未啟用 HTTPS；`/api` 代理到 `https://localhost:7032`，Demo 不會呼叫 API。日後串接 Secure Cookie 登入前須啟用 HTTPS。
若需變更後端位址，在本專案 `.env.local` 設定 `API_PROXY_TARGET`，然後重新啟動。

```bash
npm run build
npm run preview
```

建置產物位於本專案 `dist/`，本機預覽使用 4174 埠。
正式部署需提供 HTTPS，並另行設定 `/api` 反向代理；Vite 開發代理不包含在建置產物中。
目前預設部署在獨立網站的根路徑。若改放 `/admin/` 子路徑，需同步配置 Vite `base` 與未來的路由基底。
